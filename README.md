# 🚀 Nexora AI

### Gerador inteligente de landing pages com Inteligência Artificial

O **Nexora AI** é uma aplicação web que utiliza inteligência artificial para transformar descrições em páginas HTML e CSS.

O usuário descreve o tipo de site que deseja criar, e a aplicação utiliza a **API da Groq** para gerar automaticamente uma landing page personalizada, disponibilizando o código-fonte e uma prévia visual do resultado.

O projeto foi desenvolvido com o objetivo de explorar a integração entre desenvolvimento web, inteligência artificial e comunicação entre frontend e backend.

---

## 🎯 Objetivo do projeto

Facilitar a criação de landing pages utilizando inteligência artificial, permitindo que o usuário transforme uma ideia em uma interface web sem precisar escrever todo o código manualmente.

Além disso, o projeto proporciona uma experiência prática com APIs, servidores, requisições HTTP e desenvolvimento web.

## ✨ Funcionalidades

- **Geração de sites com IA:** criação de landing pages a partir de descrições em linguagem natural.
- **Personalização por prompts:** o usuário descreve o tema, estilo e características desejadas.
- **Código gerado automaticamente:** produção de estruturas HTML e CSS.
- **Pré-visualização:** exibição da página gerada diretamente na aplicação.
- **Integração com a Groq:** comunicação com um modelo de inteligência artificial.
- **Backend com Node.js:** processamento das requisições e comunicação com a API.
- **Proteção de credenciais:** utilização de variáveis de ambiente para armazenar a chave da API.
